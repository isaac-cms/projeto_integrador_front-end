Estilização do EcoTrip

Nesta atividade, a estrutura HTML das aulas anteriores recebe uma camada visual organizada com CSS3, sem utilizar Flexbox ou Grid.

O que foi aplicado?

Foram utilizados reset, variáveis CSS, seletores, combinadores, pseudo-classes, especificidade, box model, tipografia, links, tabelas, listas, bordas e fundos.

A ideia é demonstrar que o CSS controla a apresentação sem modificar a estrutura semântica do HTML.

Dicas para uma viagem mais consciente

  • Priorize transporte coletivo ou compartilhado.
  • Valorize pequenos negócios da região.
  • Evite desperdícios durante a viagem.
  • Respeite os espaços naturais visitados.
