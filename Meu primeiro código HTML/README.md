# Meu primeiro código HTML

Primeira página HTML desenvolvida no Visual Studio Code como exercício inicial de desenvolvimento web.

## Conteúdo

- Estrutura básica HTML5
- Títulos e parágrafos
- Imagem com texto alternativo
- Lista de tecnologias
- Link externo
- Botão com JavaScript

## Observação

O arquivo `index.html` referencia uma imagem chamada `minha-foto.png`. Para exibir a foto no GitHub/ao abrir a página, a imagem deve ser adicionada nesta mesma pasta.
