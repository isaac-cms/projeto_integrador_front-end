# Lógica e Análise de Dados com JavaScript

## Objetivo
Usar JavaScript para analisar informações de destinos do EcoTrip, seguindo a ideia de dados, classificação e resumo.

## O que foi aplicado
- Variáveis com `const` e `let`, objetos e array.
- Entrada com `prompt()`, conversão com `Number()` e validação.
- Classificação com `if`, `else if` e `else`.
- Escolha de mensagens com `switch`, `case`, `break` e `default`.
- Laço `for...of` para percorrer os destinos e resumir as vagas.
- Laço `while` para consultar destinos até digitar "sair".
- Template literals e `console.table()` para mostrar os resultados.
- Comentários com pseudocódigo e teste de mesa.

## Dados analisados
A lista contém cinco destinos, cada um com nome, tipo de passeio e quantidade de vagas. A análise classifica a disponibilidade e permite filtrar os destinos pela quantidade mínima de vagas.

## Como testar
1. Abra o arquivo `index.html` no navegador.
2. Responda à pergunta sobre a quantidade mínima de vagas.
3. Abra o console do navegador com F12 para acompanhar o relatório.
4. Digite o nome de um destino nas consultas e use "sair" para encerrar.
