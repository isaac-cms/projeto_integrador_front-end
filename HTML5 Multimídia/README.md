# Atividade 04 — HTML5 Multimídia

Seção multimídia do EcoTrip com vídeo em MP4 e WebM, fallback entre formatos, `poster`, legendas WebVTT, `preload` justificado e demonstração de `canPlayType()` no DOM.

Os arquivos de mídia ficam nesta própria pasta para que a atividade seja independente das demais.
