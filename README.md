# EcoTrip — Projeto Integrador Front-end

Projeto acadêmico de Front-end para Web com foco em turismo sustentável.

## Aula 04 — Multimídia

Implementação baseada no roteiro da atividade: vídeo HTML5 com dois formatos, fallback, poster, legendas, `preload="metadata"` justificado em comentário e demonstração de `canPlayType()` no DOM.

### Arquivos de mídia

- `media/guia-ecotrip.webm` — primeira opção por eficiência/tamanho.
- `media/guia-ecotrip.mp4` — fallback de compatibilidade.
- `media/poster.svg` — imagem exibida antes da reprodução.
- `media/legendas.vtt` — três blocos de legendas.

### Como executar

Abra `index.html` em um navegador moderno ou use um servidor local como Live Server no VS Code.
